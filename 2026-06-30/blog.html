First Steps with SIMD

I am total noob in this topic - errors may follow - proceed with caution

SIMD - single instruction, multiple data - refers to a special set of CPU instructions that are able to operate on multiple pieces of data simultaneously.

Consider adding numbers from two arrays. Doing this sequentially, one would load the integer from the first array at position 0, then the integer from the second array at position 0, then add them together. Repeat this process until all of the elements in an array are processed.

Of course, you could operate independently on multiple elements of the two arrays at the same time without causing problems and to some extent modern compilers are already smart enough to vectorize code for you.

But what if you wanted to do it yourself?

My ultimate goal here would be to learn how to accelerate text processing (important for search engines) using SIMD instructions, but since I am more familiar with various numerical computations (from my time doing ML engineering for recommender systems), I thought I'd start there.

As the first order of business, I'm going to be adding two arrays of numbers and comparing the results between a naive implementation in C (with no special compiler flags) and an implementation in C that uses ARM NEON intrinsics (since I will be running this code on a Mac).

Let's rewrite the above using ARM NEON intrinsics. Instead of iterating over each element in first_array and second_array, we are going to read the elements in groups of 4 and pass them into the intrinsic for addition as shown below:

code
1 for(int i=0;i<1024;i+=4){
2
3 uint32x4_t first_lane = vld1q_u32(first_array+i);
4 uint32x4_t second_lane = vld1q_u32(second_array+i);
5
6 uint32x4_t result_lane = vaddq_u32(first_lane, second_lane);
7 vst1q_u32(&result_array[i],result_lane);
